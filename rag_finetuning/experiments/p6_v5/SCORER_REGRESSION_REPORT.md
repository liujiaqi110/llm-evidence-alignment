## 1. 问题

Planning 组（证据覆盖生成、Planning v2 / v2.1）的答案会照抄规划清单中的内部事实编号，例如 `- F7：……`、`[F2, F3]`。4.0.1 把编号中的数字（7、2、3）当成“证据外数字”，于是：

- 内容正确（`content_ok_v4`）被低估；
- “无依据推断”被高估。

这违背了预注册口径：格式和引用问题不能掩盖内容判断。

## 2. 修改（`scripts/scoring_v4.py`，`SCORER_VERSION = "4.0.2"`）

三类编号分开处理：

| 类别 | 例子 | 4.0.2 的处理 |
|---|---|---|
| 引用 ID（12 位十六进制） | `[aaaaaaaaaa01]` | 和以前一样，不计入证据外数字；有效性由 `citation_valid` 判断 |
| 畸形 ID（8～11 或 13～16 位十六进制） | `[aaaaaaaaa02]` | 和以前一样（4.0.1 已修）：不计入证据外数字；`citation_valid` = False |
| **内部事实编号** | `F1`、`[F2]`、`- F7：` | **新增**：其中的数字不计入证据外数字；另记 `internal_fact_ids`，供引用审查使用 |
| 真正的证据外数值 | `9999 元`、`7 个工作日`（证据中没有） | 仍然计入，`content_ok_v4` = False |

- 匹配规则：`(?<![A-Za-z0-9])F\d{1,3}(?![0-9A-Za-z])`。`PDF2`、`F1234` 之类不会被当作内部编号。
- 已知局限：答案中真实出现的“F1 方程式”这类词，也会被当作内部编号。在制度问答中极少见，已写入回归测试说明。
- 用 `score_item_v4(..., scorer="4.0.1")` 可以复现上一版，用于对照。

| 测试 | 断言 |

| 列表式编号 `- F7：` | 4.0.2 不计证据外数字、内容正确；4.0.1 判错（复现原缺陷） |
