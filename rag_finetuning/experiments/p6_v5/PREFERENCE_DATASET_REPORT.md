# P6-v5 偏好数据集重建报告（provisional，未经人工审核）

> 本文所有通过率都是**程序自动检查**的结果，不是人工审核结论。`PREFERENCE_PAIR_AUDIT.csv` 中的人工字段和 `human_approved` 全部留空。
> 本阶段没有进行正式 SFT 或 DPO 训练，没有使用 test_v5。

| 项目 | 内容 |

## 2. 证据优先的自然样本（`scripts/build_pref_ef.py`）

流程：

1. 程序在同一篇训练文档中选 2～3 个小节，从每个小节中抽取**只有该小节才有**的必要事实（数量 / 期限、审批角色、禁止性规定）；
2. 程序建立“事实 → 来源片段”的映射，并用来源原句加引用拼出参考答案；
3. 7B（qwen2.5:7b Q4_K_M，温度 0.7，种子 2000 起）只负责把模板问题改写成自然问法，**不接触答案、不决定用哪些证据**；
4. 组装时用收紧后的抽取规则重新推导事实，再做检查。

| 环节 | 数量 |
|---|---|
| 文档 | 44 篇 |
| 尝试的小节组合 | 811 |
| 有小节抽不出独有必要事实，放弃 | 599 |
| 选中并交给 7B 改写 | 212 |
| **通过全部检查** | **161（75.9%）**，覆盖 39 篇文档；2 片段 107 道、3 片段 54 道 |

未通过的 51 道：

| 原因 | 数量 |
|---|---|
| 改写后的问题与某个选中小节没有内容重合（问题其实不需要该小节） | 23 |
| 收紧抽取规则后，有小节不再有独有必要事实 | 21 |
| 改写问题里直接写出了必要事实 | 4 |
| 伪多证据（组装后单个片段已含全部必要事实） | 1 |
| 问题长度或形式不合格 | 1 |
| 参考答案未通过评分器自检 | 1 |

对照：旧流程由 7B 自由出题，259 道中只有 14 道通过（5.4%），主要原因是 7B 只用了一个小节。

**审计中发现并修正的问题**：第一版角色抽取规则过宽，会抽出“员工档案需经部门经理”“销申请需经部”这类跨词片段。规则收紧了两次，第一版输出已存档为 `natural_ef_v10_archived.jsonl`，没有覆盖。

## 4. 偏好对（`scripts/build_pref_pairs.py`）

规则在构造前写定（见脚本头部注释）：

- **chosen**：必须覆盖全部必要事实，并通过 4.0.2 完整检查（内容、格式、陈述支持、事实归属、多证据完整）。优先用 3B 自己写出的正确答案（v3 > v4 > Base），没有时用构造保证正确的参考答案。
- **rejected**：
  - 优先用 3B Base / v3 / v4 的真实错误，且必须是**可解释的错误**；含无效 ID、证据外数字或过短的不用。
  - 只有某题没有真实的核心错误时，才用人工构造的负例，方法只限删减句子或替换引用，不编造事实。
  - 两类分开标记。
- 排除：只有引用 / 格式差异；语义等价或偏好不明确；chosen 未通过检查。
- 每题最多 2 对。
- 长度偏差上限：“chosen 比 rejected 长”的对占比 ≤ 0.65。超出时先删除长度差最大的人工构造对。

|---|---|
| 正文平均字数 | chosen 103.1，rejected 91.1 |

## 5. AI 抽查（≠ 人工审核）

我随机抽了 4 对，另抽 3 道 H 类真实错误，共 7 对，逐条对照证据。大多数偏好清楚，例如：

- 漏掉“8 小时 / 3 次”；
- 漏掉“财务经理”；
- 把“延长至 6 天”的出处引成另外两个片段；
- 引用 ID 写坏（`d3a46887aml`，不是十六进制，评分器没把它识别成 ID）。

**发现的偏好不清问题**：

1. **H 类（引用错误）占 33.5%，是最大的一类，也是偏好最弱的一类。**
   - 298 对 rejected 的事实覆盖率不低于 chosen，全部是 H / I / G / F 这类行为或引用偏好：H 265、I 24、G 7、F 2。
   - 135 道 H 类真实错误中，60 道 rejected 比 chosen 更长，有的内容还更完整，区别只在某句的引用片段。
   - 如果某个片段也能支持该句，这一对就是**偏好不明确**的，需要人工判断。
2. **52% 的 chosen 是程序拼出的参考答案。**
   - 文风是“原句 + 引用”，比 3B 的自然回答平均长约 30 字（117.7 对 87.1）。
   - 这对 DPO 是离策略样本，可能让模型偏向照抄原句的文风。
3. **类型不均衡。** D（7）、F（2）太少，无法单独训练出可靠效果；C、I 全部是人工构造。
4. **结构化样本模板化。** 训练题内部有 21 对相似度 > 0.8 的近重复，例如“金额 6000 元的 X，谁来批？”，题面只差名词，证据来自不同文档。
5. **评分器漏判写坏的引用 ID。** 有些 ID 坏得连十六进制都不是（如 `d3a46887aml`），评分器不会识别成 ID，所以这类输出没被当成无效 ID 剔除。它们仍然是真实错误，可以作 rejected，但错误说明写的是“引用错误”而不是“无效 ID”。

## 6. 结论（provisional）

- 数据构造满足本阶段的硬性要求：
  - 只用训练语料；
  - 真实错误为主（66%），真实与构造分开标记；
  - chosen 全部覆盖必要事实；
  - 排除原因全部有记录；
  - 长度偏差在预设上限内；
  - 泄漏检查全部通过。
- **不能视为已审核的数据集。** 正式训练前至少需要人工审核：
  - H 类偏好对（至少抽 60 对）；
  - 以参考答案作 chosen 的对（至少抽 40 对）；
  - 全部 C / I 人工构造对。
- 建议的预注册处理见 `DPO_EXPERIMENT_PLAN.md`。
